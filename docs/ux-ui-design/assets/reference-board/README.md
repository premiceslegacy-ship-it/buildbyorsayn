# Reference board

Ces images servent de boussole esthétique par défaut pour le skill.

Dans BUILD ou sur un projet client, elles peuvent être remplacées par les références de l'utilisateur : screenshots, sites, apps, marques, photos, logos, typographies, palettes ou assets produit.

- `01-modular-dark-creative.png` : grille premium, fonds sombres, images cinématiques, cards asymétriques.
- `02-mobile-story-cards.jpg` : mobile first, cards verticales, motion blur doux, copy court, esthétique éditoriale.
- `03-polaris-cinematic-hero.jpg` : hero immersif, nav glass capsule, profondeur atmosphérique, CTA discret.

Ne pas copier les compositions. Extraire la sensation : calme, profondeur, désirabilité, simplicité.
