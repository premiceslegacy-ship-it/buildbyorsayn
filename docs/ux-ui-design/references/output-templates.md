# Output Templates

Utiliser ces structures pour produire des livrables cohérents. Adapter le contenu au projet, mais garder la précision.

## DA-SYNTHESIS.md

```markdown
# DA-SYNTHESIS - [Projet]

## 1. Sensation cible
[3 à 5 mots précis]

## 2. Perception en 2 secondes
[L'utilisateur doit comprendre et ressentir quoi immédiatement]

## 3. Références positives
- [Référence] : [ce qu'on garde]
- [Référence] : [ce qu'on garde]
- [Référence] : [ce qu'on garde]

## 4. Anti-références
- [Direction refusée] : [raison]
- [Direction refusée] : [raison]
- [Direction refusée] : [raison]

## 5. Fond, lumière, surface
[Couleurs, profondeur, glass, overlays, contraste]

## 6. Imagerie
[Type d'assets, cadrage, lumière, mouvement, interdits]

## 7. Copywriting
[Voix, niveau de simplicité, promesse, CTA]

## 8. Mobile first
[Structure 375 px, action principale, navigation, priorités]

## 9. Décision DA
[Direction validable en 2 à 3 phrases]
```
