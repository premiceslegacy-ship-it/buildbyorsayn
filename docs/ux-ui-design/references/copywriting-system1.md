# Copywriting Système 1

Le copywriting doit parler au cerveau rapide : perception immédiate, bénéfice évident, friction basse, action simple.

La règle : l'utilisateur ne doit pas décoder. Il doit reconnaître un problème, voir une promesse crédible et comprendre la prochaine action.

## Hiérarchie de persuasion

Ordre obligatoire :

```text
1. Résultat client.
2. Friction supprimée.
3. Preuve ou mécanisme crédible.
4. Action simple.
```

Ne jamais commencer par la technologie si le bénéfice n'est pas évident.

## Test des 2 secondes

Un hero, une ad ou un écran onboarding doit répondre à ces questions en 2 secondes :

```text
C'est pour qui ?
Qu'est-ce que ça change pour lui ?
Pourquoi maintenant ?
Que dois-je faire ensuite ?
```

Si une question reste floue, réécrire.

## Structure des titres

Un bon titre combine :

```text
Bénéfice concret + tension émotionnelle + simplicité
```

Exemples de structures :

```text
Gagne [résultat] sans [friction]
Transforme [situation pénible] en [résultat désiré]
Le moyen le plus simple de [objectif]
Tout ce qu'il te faut pour [résultat], sans [complexité]
[Résultat] en [délai ou effort réduit]
Arrête de [douleur]. Commence à [résultat].
```

## Titres faibles à corriger

```text
Mauvais : Une solution innovante pour votre entreprise.
Bon : Automatise les tâches qui ralentissent ton équipe.

Mauvais : La nouvelle génération de productivité.
Bon : Passe de la demande client à la réponse prête en 2 minutes.

Mauvais : Découvrez notre plateforme intelligente.
Bon : Trouve la bonne information avant d'ouvrir 6 outils.

Mauvais : Boostez votre workflow.
Bon : Termine le travail répétitif avant 9h.
```

## Descriptions

La description sous un titre doit clarifier, pas répéter.

Format recommandé :

```text
[Qui] obtient [résultat] grâce à [mécanisme simple], sans [friction principale].
```

Exemples :

```text
Les dirigeants gardent une vue claire sur leurs opérations, sans courir après les fichiers, les messages et les relances.

Ton équipe transforme chaque demande entrante en action prête à exécuter, sans copier-coller entre outils.
```

## CTA

Un CTA doit promettre une prochaine étape claire. Il ne doit pas demander un effort abstrait.

Formules :

```text
Voir mon audit
Créer mon espace
Lancer l'analyse
Obtenir le plan
Tester le workflow
Réserver ma démo
Voir le résultat
Générer ma première page
```

CTA secondaire :

```text
Voir un exemple
Comparer les plans
Lire le cas client
Explorer les use cases
Regarder la démo
```

Micro-réassurance sous CTA :

```text
Sans carte bancaire.
Configuration en 3 minutes.
Audit offert, réponse sous 24h.
Tu gardes le contrôle à chaque étape.
```

Interdits :

```text
En savoir plus
Cliquer ici
Soumettre
Envoyer
Découvrir
Commencer maintenant, si le bénéfice n'est pas clair
```

## Microcopy

La microcopy doit réduire l'anxiété.

Règles :

- écrire comme un humain utile ;
- expliquer ce qui va se passer ;
- ne jamais blâmer l'utilisateur ;
- dire comment récupérer une erreur ;
- rester court.

Exemples :

```text
Erreur faible : Champ invalide.
Erreur forte : Ajoute une adresse email valide pour recevoir ton accès.

Empty state faible : Aucun résultat.
Empty state fort : Aucun résultat pour l'instant. Modifie le filtre ou crée ton premier workflow.

Loading faible : Chargement.
Loading fort : Analyse de tes données en cours. Cela prend quelques secondes.
```

## Ads

Une ad doit vendre l'après, pas la feature.

Structure :

```text
Hook visuel : image premium qui arrête le scroll.
Hook textuel : problème ou résultat en moins de 9 mots.
Body : une phrase de clarification.
Proof : chiffre, délai, exemple ou mécanisme.
CTA : action simple.
```

Angles publicitaires premium :

```text
Angle douleur : Tu perds encore du temps sur [tâche répétitive] ?
Angle résultat : [Résultat] avant la fin de la journée.
Angle contraste : Moins d'outils. Plus de décisions.
Angle statut : Une interface qui donne confiance avant même la démo.
Angle simplicité : Le système travaille pendant que ton équipe avance.
Angle preuve : [X] heures récupérées chaque semaine sur [process].
```

Exemples ads :

```text
Hook : Tes relances ne devraient pas dépendre de ta mémoire.
Body : Automatise les suivis clients, garde le ton humain, récupère du temps chaque semaine.
CTA : Voir le workflow

Hook : Une page premium avant ton prochain call.
Body : Génère une landing claire, crédible et orientée conversion à partir de ton brief.
CTA : Créer ma page

Hook : Moins de chaos. Plus de réponses prêtes.
Body : Centralise les demandes, génère les prochaines actions et garde ton équipe alignée.
CTA : Tester le système
```

## Copy hero premium

Structure :

```text
Eyebrow : preuve, audience ou tension.
Titre : bénéfice direct en 5 à 9 mots.
Description : résultat + mécanisme + friction supprimée.
CTA principal : action + bénéfice.
CTA secondaire : preuve ou exemple.
Réassurance : friction retirée.
```

Exemple :

```text
Eyebrow : Pour les équipes qui veulent avancer sans friction.
Titre : Transforme chaque demande en action claire.
Description : Orsayn connecte tes outils, prépare les réponses et automatise les suivis sans casser tes process existants.
CTA principal : Voir mon workflow
CTA secondaire : Explorer un cas client
Réassurance : Audit offert, sans engagement.
```

## Vocabulaire

Mots forts dans cette DA :

```text
clair, précis, fluide, maîtrisé, calme, instantané, fiable, visible, aligné, prêt, simple, premium, contrôlé, vivant, utile, net, direct
```

Mots à éviter :

```text
innovant, révolutionnaire, disruptif, solution, transformation digitale, booster, optimiser sans preuve, nouvelle génération, plateforme tout-en-un, expérience unique
```

## Système anti jargon

Avant de rendre un texte, remplacer :

```text
Nous aidons les entreprises à optimiser leurs processus.
```

par :

```text
Ton équipe passe moins de temps à relancer, copier, vérifier et reporter.
```

Remplacer :

```text
Notre IA révolutionne votre productivité.
```

par :

```text
Les tâches répétitives avancent même quand ton équipe est occupée.
```
